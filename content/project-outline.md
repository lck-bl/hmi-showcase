# 项目名称
基于 PAD 情绪量表的用户画像及 HMI 自适应设计

# 项目背景
传统车载 HMI 多停留在功能展示和被动响应层面，难以满足复杂驾驶场景中驾驶员情绪调节与交互支持的需求。

# 研究目标
结合 PAD 情绪量表和情景感知理论，构建静态特质与动态情绪结合的驾驶员用户画像，并推导不同驾驶场景下的自适应 HMI 设计策略。

# 核心方法
1. PAD 情绪模型
2. 情景感知理论
3. 用户画像构建
4. 场景—情绪—需求映射
5. 自适应 HMI 策略
6. 眼动、生理信号、PAD/SUS 主观量表验证

# 四类驾驶场景
1. 通勤拥堵
2. 低能见度
3. 易驾驶分心
4. 常态平静

# 实验验证
通过眼动数据、生理信号、PAD 自评量表和 SUS 系统可用性量表，验证自适应 HMI 方案的有效性。

# 最终输出
自适应 HMI 高保真视觉设计方案。
